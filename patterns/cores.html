cores.html

Cor: seis valores e um laranja escasso.

A paleta é fechada: seis cores de marca, cinco variantes de trabalho e nada mais. Toda camada consome papéis semânticos (--paper, --ink, --accent), nunca o valor cru, e os dois momentos, laranja e escuro, trocam o valor de cada papel sem trocar o nome. O laranja tem quatro papéis e um teto de três por página.

6 cores

Laranja, branco, preto, chumbo, papel e tinta. As variantes (laranja aprofundado, chumbo 2, areia, tinta 2, noite) derivam delas e ficam sob o mesmo prefixo --8020-.

Nenhuma cor fora do prefixo entra em CSS ou SVG. O brand.json guarda a matriz de contraste medida para cada par de texto e fundo.

Os seis primitivos

Os valores da marca vivem em tokens/8020.css com o prefixo --8020-. As seis cores são a identidade; as cinco variantes existem para o momento laranja, o momento escuro, a contenção sem borda e o corpo de texto. Nenhuma camada usa esses valores direto: entram só pelos papéis.

0 cores novas

Precisou de uma cor que não está aqui, a resposta é a rampa de tinta ou o laranja no papel certo.

Vermelho de erro não existe: erro é laranja funcional. Verde de sucesso não existe: sucesso é a palavra escrita. Dado negativo é chumbo.

3 momentos

Papel é a base. Laranja e escuro são momentos: uma classe no slide, na seção ou no bloco, e todos os papéis mudam juntos.

Dentro do laranja, --accent vira branco e --ink-body vira preto: o texto pequeno nunca fica branco sobre laranja.

A ação primária dentro do momento laranja é branca com texto preto; a secundária é a quieta, em preto.

Os quatro papéis do laranja

O laranja aparece em quatro papéis e só neles: momento (o fundo de .tema-laranja e da .faixa.laranja), ação primária dentro do momento (o botão branco), estado atual (o quadrado de 8 px) e o 20 do dado (o elemento que a leitura em palavras nomeia). Nunca em corpo, nunca em rótulo pequeno, nunca em borda. Escassez é o que dá impacto: no máximo três momentos de acento por página ou slide.

Momento e ação primária dentro dele

O momento é o fundo laranja de um slide inteiro (.s-cheio.tema-laranja), de uma seção (section.momento.tema-laranja) ou de uma faixa de separatriz. Um por capítulo quando é página inteira, nunca em dois slides seguidos. Dentro dele a ação primária é o bloco branco, e a chapa de registro também é branca. O bloco laranja da seção de papéis semânticos mostra os dois.

Estado atual

O quadrado de 8 px em laranja marca o que está acontecendo agora: o item em revisão, o selo do que é atual ou novo. Cheio em tinta é informação; contorno é feito; --rule-strong é parado.

A matriz de contraste

Cada papel de texto contra cada fundo, nos três momentos, calculado ao vivo a partir do CSS carregado: a página lê a cor computada de cada papel, compõe a transparência sobre o fundo e aplica a fórmula do WCAG 2. Os valores batem com a matriz medida do brand.json.

Níveis: AAA a partir de 7:1; AA a partir de 4,5:1; AA-grande a partir de 3:1, que só serve para texto de 24 px ou de 19 px em peso 700; reprova abaixo de 3:1. O que fica em laranja na tabela só serve para texto grande.

A fórmula

Luminância relativa: cada canal dividido por 255 e linearizado, por 12,92 quando o valor é até 0,03928, senão por ((c + 0,055) / 1,055) elevado a 2,4; L = 0,2126 R + 0,7152 G + 0,0722 B. Razão: (L1 + 0,05) / (L2 + 0,05), com a luminância maior em cima. Cor com transparência é composta sobre o fundo antes da conta: canal do texto vezes alfa, mais canal do fundo vezes (1 menos alfa).

Código
(function () {
  /* A matriz de contraste, calculada ao vivo a partir do CSS carregado. Para cada momento,
     cria um elemento de sonda com a classe do momento, lê a cor computada de cada papel de
     texto e de fundo, compõe a transparência sobre o fundo e aplica a fórmula do WCAG 2. */
  var alvo = document.getElementById("matriz-contraste"), sonda = document.getElementById("sonda");
  if (!alvo || !sonda) return;
  function lin(c) { c = c / 255; return c <= 0.03928 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4); }
  function lum(rgb) { return 0.2126 * lin(rgb[0]) + 0.7152 * lin(rgb[1]) + 0.0722 * lin(rgb[2]); }
  function razao(a, b) { var x = lum(a), y = lum(b); return (Math.max(x, y) + 0.05) / (Math.min(x, y) + 0.05); }
  function ler(s) { var m = (s.match(/[\d.]+/g) || []).map(Number); return { rgb: [m[0], m[1], m[2]], a: m.length > 3 ? m[3] : 1 }; }
  function compor(fg, bg) { return fg.rgb.map(function (v, i) { return Math.round(v * fg.a + bg[i] * (1 - fg.a)); }); }
  function hex(rgb) { return "#" + rgb.map(function (v) { return v.toString(16).padStart(2, "0"); }).join(""); }
  function nivel(r) { return r >= 7 ? "AAA" : r >= 4.5 ? "AA" : r >= 3 ? "AA-grande" : "reprova"; }
  var textos = ["ink", "ink-body", "ink-soft", "muted", "meta", "accent"], fundos = ["paper", "surface", "surface-2"];
  var momentos = [["papel", ""], ["laranja", "tema-laranja"], ["escuro", "tema-escuro"]];
  momentos.forEach(function (m) {
    var caixa = document.createElement("div"); caixa.className = m[1]; sonda.appendChild(caixa);
    function cor(prop, papel) { var e = document.createElement("i"); e.style[prop] = "var(--" + papel + ")"; caixa.appendChild(e); return ler(getComputedStyle(e)[prop]); }
    var papel = cor("backgroundColor", "paper").rgb, fundo = {};
    fundos.forEach(function (f) { fundo[f] = compor(cor("backgroundColor", f), papel); });
    var cabeca = "<tr><th>Texto</th>" + fundos.map(function (f) { return "<th class='num'><code>--" + f + "</code> <span class='nivel'>" + hex(fundo[f]) + "</span></th>"; }).join("") + "</tr>";
    var linhas = textos.map(function (t) {
      var fg = cor("color", t);
      return "<tr><td><code>--" + t + "</code></td>" + fundos.map(function (f) {
        var c = compor(fg, fundo[f]), r = razao(c, fundo[f]);
        return "<td class='num " + (r >= 4.5 ? "ok" : "baixo") + "'><span class='sw' style='background:" + hex(c) + "'></span>" + r.toFixed(2).replace(".", ",") + ":1<span class='nivel'>" + nivel(r) + "</span></td>";
      }).join("") + "</tr>";
    }).join("");
    alvo.insertAdjacentHTML("beforeend", "<div><h3>Momento " + m[0] + " <span>papel " + hex(papel) + "</span></h3><div class='rolagem'><table><thead>" + cabeca + "</thead><tbody>" + linhas + "</tbody></table></div></div>");
  });
})();
4,5:1

--meta é a cor mais clara permitida para texto: 4,7:1 sobre o papel, o mínimo do sistema, e só a partir de 11,5 px.

--accent sobre o papel dá 3,3:1: por isso o laranja é acento de título, momento, ação e estado, nunca corpo.

Branco sobre laranja dá 3,5:1. Só a partir de 24 px, ou 19 px em 700; por isso o texto pequeno do momento laranja é preto.

O que é proibido

Quatro pares e uma regra fecham a paleta. O que está fora entra só por decisão registrada no projeto, nunca por conveniência de um slide.

Branco sobre laranja abaixo de 24 px3,5:1 só passa como texto grande (24 px, ou 19 px em 700). O texto pequeno do momento laranja é preto, e a camada resolve isso pelos papéis; não sobrescrever.
Laranja sobre papel abaixo de 24 px3,3:1. O laranja é acento de título, momento, ação e estado, nunca corpo, nunca rótulo pequeno, nunca link.
Laranja sobre laranjaSem contraste. Dentro do momento laranja o acento é o branco: o botão, a chapa, o 20 do dado e o anel de foco ficam brancos.
